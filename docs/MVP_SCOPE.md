# MVP Scope

## Target Users

- University students exploring technology career options
- Recent graduates seeking direction for early-career technology roles

## In-Scope Features

- Student profile creation and editing
- Career assessment questionnaire
- Top three AI-generated career recommendations
- Confidence scores for each recommendation
- Explanations describing why each career was recommended
- Skill-gap analysis for a selected career
- Personalised learning roadmap
- Recommendation history for each student profile

## Out-of-Scope Features

- Mobile application
- Real-time job vacancy scraping
- Payments
- Social networking
- Live career counsellor chat
- Complex administrator portal
- Production cloud deployment
- Full institutional integration

## Initial Careers

- Software Developer
- Data Analyst
- Cybersecurity Analyst
- Cloud Engineer
- Network Administrator
- Database Administrator
- UI/UX Designer
- AI/ML Engineer

## MVP Acceptance Criteria

- A student can create and update a profile containing relevant academic background, interests, and existing skills.
- A student can complete a career assessment questionnaire through the web application.
- The system returns exactly three recommended careers from the supported initial career list.
- Each recommendation includes a confidence score that can be presented clearly to the user.
- Each recommendation includes a plain-language explanation tied to the student's input.
- A student can select a recommended career and view a skill-gap analysis against that role.
- The system provides a personalised learning roadmap for the selected career.
- Previous recommendation results are stored and can be reviewed later by the same student.
- The MVP operates using the planned development stack, including Blazor, EF Core, SQLite, and ML.NET.
